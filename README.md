# Fake One-Handed Mode · 伪单手模式

一个基于 LSPosed 的单手模式模块：把完整手机界面等比缩到左下角或右下角，恢复老安卓系统的缩屏单手操作逻辑。

**本项目完全 Vibe Coding，有问题尽量修。**

作者：[流浪本子商人](https://github.com/JohnWongHZW)

## 单手模式

- 整个界面等比缩小，包括桌面、应用切换和键盘，空余区域保持黑色。
- 支持左手、右手，缩小后的画面带圆角。
- 提供 **60% / 70% / 80%** 预设，默认 **60%**；支持输入 **40%–85%** 的自定义整数比例。
- 百分比作用于宽和高，无需填写屏幕英寸或校准尺寸。
- 开启后可以直接调整比例和左右手，立即生效，配置自动保存。
- **双击空白处任意位置退出**，单击空白处不会退出。
- 解锁后在竖屏手势导航下，从底部小白条区域左半侧或右半侧向下滑，分别进入左下角或右下角；从小窗底部向上滑退出。空白区只显示双击退出提示。
- 在匹配的小米系统界面中，模块会将自由小窗装饰手势的物理坐标换算到缩小后的任务空间，支持拖动和调整大小。接口参考 [OnehandedMode 的小米适配](https://github.com/wushidia/OnehandedMode/blob/4fe05687803777dc0c03c920762fb711971eca5f/app/src/main/java/io/githuh/onehandedmode/hook/XiaomiFreeformCoexist.kt)。
- 控制中心提供 **伪单手模式** 快捷开关，按已保存的配置开启或退出。

## 卢本伟模式

首页底部的小入口：**（作者的妙妙小功能）**。

> 我卢本伟没有开挂

- 横拿手机时，完整画面等比显示在最左侧，最多占横屏宽度的三分之一，其余区域保持黑色。
- 开启时保存媒体音量并归零，退出时恢复原来的媒体音量。
- 开启后直接生效，熄屏不会自动退出。
- 与普通单手模式互斥，切换时会先恢复当前模式。

## 其他功能

- 两种模式均为已识别的通知面板和最近任务视图按自身宽高绘制模糊壁纸背景。动态壁纸使用系统提供的当前画面快照。
- 查看、复制、清理模块运行日志。
- 隐藏桌面图标，仍可从 LSPosed 模块设置进入。
- 首页提供使用教程、关于与作者 GitHub 入口。
- 绿色 Material 3 Expressive 风格界面，支持深浅主题；卢本伟模式保留独立的紫色页面和图标。

## 开启与退出

安装 Release 中的 APK，在 LSPosed 启用模块，勾选 **系统框架（system）、系统界面（com.android.systemui）和小米桌面（com.miui.home）**，重启手机后使用。需要支持 **libxposed API 102** 的框架；无需配套其他模块或额外给应用授予 root 权限。

普通单手模式在竖屏时开启，可再次点击首页按钮、控制中心开关，或双击空白区域退出；熄屏也会退出。

两种模式均支持 **2 秒内连按 3 次音量减** 恢复，单次运行上限为 **2 小时**，重启后默认关闭。也可以使用页面中的恢复按钮。

有问题可到 [Issues](https://github.com/JohnWongHZW/Fake-One-Handed-Mode/issues) 反馈，附上手机型号、系统版本、LSPosed 版本及模块日志，方便排查。
